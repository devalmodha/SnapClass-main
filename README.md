# 📸 SnapClass – AI Powered Attendance System

> **An intelligent attendance management system that automates classroom attendance using AI-powered face recognition, making the process faster, smarter, and more accurate.**

---

## 🚀 Overview

SnapClass is an AI-based attendance management system designed to eliminate manual attendance taking in classrooms. By utilizing computer vision and facial recognition, the system automatically identifies students and marks attendance in real-time.

The project aims to reduce time, prevent proxy attendance, improve accuracy, and provide an easy-to-use dashboard for teachers and administrators.

---

## ✨ Features

### 🤖 AI Face Recognition
- Detects multiple faces in real-time
- Recognizes registered students
- High accuracy attendance marking

### 📸 Real-Time Camera Capture
- Live webcam integration
- Instant face detection
- Automatic attendance recording

### 👨‍🎓 Student Management
- Add new students
- Update student details
- Delete student records
- Register student face data

### 📅 Attendance Management
- Automatic attendance generation
- Daily attendance records
- Date-wise attendance history
- Manual attendance correction (optional)

### 📊 Dashboard
- Total students
- Present students
- Absent students
- Attendance statistics

### 🔐 Secure Login
- Admin authentication
- Teacher login
- Secure access to attendance records

### 📁 Data Management
- Store student information
- Attendance database
- Face image dataset
- Attendance reports
